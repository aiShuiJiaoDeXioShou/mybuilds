# 功能规范：FRP 远程接入

**Feature Branch**: `main`（规划编号独立于分支）

**Created**: 2026-10-09

**Status**: 已规划，尚未部署

**Input**: 用户希望利用 FRP 暴露控制端端口，并先规划实现。

## User Scenarios & Testing

### User Story 1 - 通过公网地址使用控制端（P1）

用户在其他机器使用稳定地址连接自己的控制端，查询项目、触发普通构建、跟踪日志和下载结果；已有身份和节点无需重新初始化。

**Why this priority**: 远程接入不再依赖每台客户端单独维护 SSH 隧道。

**Independent Test**: 在独立客户端经新地址查询状态，完成一次普通构建及报告、制品下载。

**Acceptance Scenarios**:

1. 正确身份能查询状态，缺失或错误身份被拒绝；连接需要验证服务端证书。
2. 普通构建的实时日志、报告摘要和下载内容与控制端本地查询一致，文件摘要相同。
3. 多报告消息和制品沿现有容量及时间预算传输，代理不引入更小的容量或缓存整个日志流。

### User Story 2 - 保留现有访问与可恢复运行（P1）

管理员增量接入新地址，原有 SSH 和同机节点仍能运行；接入失败时能恢复原连接而不重置数据。

**Why this priority**: 现有 FRP 可能承载其他服务，新接入不能中断它们。

**Independent Test**: 核对接入前后的原访问、节点状态及数据，停止新隧道后恢复旧连接。

**Acceptance Scenarios**:

1. 接入后旧 SSH 路径、同机节点和现有项目保持可用；控制端仍只在本机监听。
2. 隧道断开后不得伪造构建成功或重新执行动作；隧道恢复后可重新查询状态。
3. 配置和程序有备份、明确的启停方式；回退后原连接通过，既有数据与身份保留。

### Edge Cases

- 域名或证书未准备、端口冲突、隧道身份或证书错误、IPv6 存在额外暴露。
- 共享 FRP 修改全局绑定影响原 SSH、公网绕过 HTTPS 直接访问明文转发端口。
- 隧道断开、日志流被缓冲、请求或制品大小被代理提前拒绝。
- 旧控制端或 Agent 不接受新版工作流；运行中任务不能通过直接停止 Agent 完成升级。

## Requirements

### Functional Requirements

- **FR-001**：采用外部 FRP 服务转发现有控制端，不新增应用内隧道执行器或远程 API。
- **FR-002**：公网使用校验证书的 HTTPS；跨主机隧道加密并验证中转服务器身份，已有 mybuilds 身份仍生效。
- **FR-003**：控制端维持回环监听，新明文转发端口不能从外网访问；不重新生成 token 或数据库。
- **FR-004**：保留实时日志和文件流语义，不缩减现有 8 MiB 报告消息及制品容量，不改变业务时间预算或重试语义。
- **FR-005**：复用已有 FRP 时增量添加代理，不更改可能影响旧代理的全局监听范围；接入前后验证原 SSH 路径。
- **FR-006**：隧道独立托管、支持重连；中断继续沿现有租约和未知结果保护处理，不重新执行已开始步骤。
- **FR-007**：提供版本、配置、凭据位置、启停、验收与回退记录；只有真实通过才更新部署状态。
- **FR-008**：使用同一代码版本升级相关控制端和 Agent 后再应用新版工作流，先停接单、等待任务结束并备份；不自动发布商店或部署应用。

### Key Entities

- 接入端点：用户访问地址及证书归属，对应一个已有控制端。
- 隧道映射：中转端口与控制端回环端口，独立于构建节点。
- 部署记录：版本、配置和备份位置、真实验证结果及回退状态，不包含明文凭据。

## Success Criteria

- **SC-001**：独立客户端状态查询成功，错误身份与错误证书均不能访问。
- **SC-002**：一次普通构建的实时日志、至少 70 份报告及一个制品可查询下载，大小和摘要全部对应。
- **SC-003**：原 SSH、同机节点和项目查询在切换后仍通过，公网明文入口不可达。
- **SC-004**：断开与恢复、服务重启及回退各有实际记录，回退不删除或重建既有数据与身份。

## Assumptions

- 本次交付规划；公网部署、远端升级和实际切换属于后续实施任务。
- 优先复用当前中转服务器，域名、frps 地址/端口、授权方式与证书路径在部署前填写为环境参数。尚未填写不等同技术方案存在歧义。
- 客户端和远端控制端、Agent 可以分别升级；同机 Agent 保留回环连接，只把跨机器的连接切换到新 HTTPS 地址。
- 当前本机客户端已经升级，远端状态仍报告 v0.1.0，不能把本次本机升级当作远端升级完成。
