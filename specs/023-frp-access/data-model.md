# 部署配置关系

不新增数据库实体或API。

| 对象 | 字段/关系 | 校验 |
|---|---|---|
| 公网入口 | 访问域名、HTTPS443、证书 | 指向公网主机；证书匹配域名和信任链 |
| frps | 地址、控制端口、版本、token位置、TLS证书 | frpc版本匹配；校验证书；原代理保持 |
| 隧道映射 | 唯一name、localIP=127.0.0.1、localPort=8787、remotePort=18787（示例） | 两台主机独立查端口；新明文端口外网不可达 |
| 客户端连接 | HTTPS server、原token、可选ca_file | 仅替换server，私有CA才设置ca_file，先验证副本 |
| 节点连接 | 同机回环/跨机HTTPS、原node/token/data_dir | 同机保持；跨机独立验证 |
| 部署记录 | 版本/SHA、备份、标签、验收与回退 | 只记录凭据位置，不保存token |

状态：已规划→盘点完成→配置验证→试用通过→切换完成；失败保持旧入口并记录，不自动推进。隧道故障不改变既有租约与未知结果状态机。
