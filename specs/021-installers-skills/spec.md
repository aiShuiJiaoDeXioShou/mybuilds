# 功能规范：跨平台安装与 AI 操作技能

**Feature Branch**: `codex/installers-skills`
**Created**: 2026-10-08
**Status**: 已明确
**Input**: 创建公开 GitHub 仓库，提供服务端/客户端的一键安装脚本和 AI 操作 skills，覆盖 macOS/Linux/Windows，并安装到指定服务器与本地 shell。

## User Scenarios & Testing

### US1 - 安装并连接客户端（P1）
用户下载对应平台安装入口，一次执行后可在新 shell 调用客户端；可导入服务地址和私有 token 文件。
独立验收：空安装目录安装后 version 成功；再次安装保留连接配置；错误校验和不替换程序。

### US2 - 初始化并托管服务端（P1）
管理员一次执行完成控制端初始化、管理员连接配置、可选同机 Agent 与系统服务。
独立验收：服务启动、客户端 status、Agent 在线、演示构建和下载成功；重复执行不新增身份或覆盖配置。

### US3 - 使用 AI 技能和公开发布（P2）
用户从公开仓库获得源码和安装包，AI 根据技能完成安装、连接、构建、制品操作。
独立验收：技能可独立安装并通过格式验证，示例匹配 CLI；仓库与发行包可下载。

### Edge Cases
下载中断或哈希错误、缺少依赖、不支持的架构、已有配置或服务、并发安装、路径包含空格、没有服务管理器、Windows 未启用 WSL、凭据或连接错误必须明确报错，不能覆盖用户配置或暴露凭据。

## Requirements

### Functional Requirements
- **FR-001**：提供 macOS/Linux 的 Shell 与 Windows 的 PowerShell 客户端安装入口，安装到用户目录并持久配置 PATH。
- **FR-002**：提供 macOS/Linux 服务端安装入口，Windows 通过已安装并启用系统服务的 WSL 发行版部署；明确不支持原生 Windows 服务端。
- **FR-003**：服务端首次初始化管理员身份和私有连接配置；可选同机 Agent 单独身份；重复安装保留身份、数据库与配置。
- **FR-004**：安装包校验 SHA-256，安装前验证平台、依赖和参数；下载或校验失败不得替换已有程序。
- **FR-005**：服务由平台服务管理器托管，提供查看状态、停止与重启说明；默认仅监听回环，跨机器使用 HTTPS 或 SSH 隧道。
- **FR-006**：客户端可从私有文件导入 token 和服务地址，敏感值不出现在日志、仓库或命令参数中；已有配置不覆盖。
- **FR-007**：发布 AI 部署技能与日常操作技能，包含真实命令、默认路径、权限和发布边界，支持本地安装。
- **FR-008**：创建当前账号下公开 mybuilds 仓库，推送已验收提交，发布对应各平台安装包与校验和；不替换已有同名仓库。
- **FR-009**：在用户指定服务器安装控制端和同机 Agent，在本地 shell 安装客户端并验证完整构建、下载。

### Key Entities
发行包（版本、平台、架构、校验和）；本地安装（程序、配置、技能）；受管服务（角色、身份、日志、运行状态）。复用现有数据库，不增加业务模型。

## Success Criteria
- **SC-001**：三种系统都有可执行安装入口；支持平台完成首次与重复安装检查，不支持环境给出具体错误。
- **SC-002**：服务重启后原有身份与记录可复用，安装输出不包含 token。
- **SC-003**：指定远程环境与本地客户端完成一个真实构建及一致的制品下载。
- **SC-004**：两个 AI 技能通过格式验证，公开仓库和安装包可访问。

## Assumptions
- 当前 GitHub 账号作为仓库所有者，仓库公开；许可证仍由用户另行确定。
- Windows 原生仅客户端，服务端走 WSL；不扩大现有构建平台支持。
- 服务端可选 Agent 默认关闭，实际本次部署开启；SDK 由构建机现有环境提供。
- 新增安装不会迁移已有手工部署；检测已存在配置时保留，错误不自动重置。
- SSH 地址与凭据仅用于本次部署，禁止写入项目文件；本地连接采用专用 SSH 隧道。
