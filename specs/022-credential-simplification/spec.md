# 功能规范：精简凭据读取与重复校验

**Feature Branch**: `main`（规范目录 `022-credential-simplification`）
**Created**: 2026-10-08
**Status**: 已明确
**Input**: 用户认为权限保护和日志脱敏存在重复实现，希望降低项目复杂度。

## 用户场景与验收

### US1：只读凭据可直接使用（P1）

用户在专用构建账号下使用可信仓库，凭据仅需账号自己可读，无需额外开放写权限。

**优先原因**：精确要求可写权限会拒绝更严格的只读配置。
**独立验收**：只读管理配置、Agent 秘密文件、SSH 材料及发布/通知材料均能读取。

1. **Given** 自有普通凭据文件为 `0400` 或 `0600`，**When** 实际消费者读取，**Then** 两种权限均可用。
2. **Given** 凭据公开可读或是叶符号链接、FIFO，**When** 实际消费者读取，**Then** 明确失败且不阻塞读取。
3. **Given** Agent 配置引用尚未部署的秘密文件，**When** 只加载配置，**Then** 返回解析后的路径；实际任务使用前读取失败，不执行脚本或上传。

### US2：凭据选择规则只有一份（P2）

维护者使用同一组规则选择构建与发布查询所需的秘密，减少规则漂移和无效错误分支。

**优先原因**：减少重复判断且保持实际执行边界。
**独立验收**：普通步骤、post、签名、商店上传和自定义查询继续只取得声明的业务秘密。

1. **Given** 已声明业务秘密与节点控制凭据，**When** 构建或发布查询选择秘密，**Then** 保留业务秘密并过滤节点/客户端 token、宿主 SSH 材料及等值运行 token。
2. **Given** 秘密跨日志输出块或 stdout/stderr 并发输出，**When** 收集日志，**Then** 已知秘密仍被替换，普通文本完整保留。

## 边界情况

- `0400` 只针对读入的材料；可写 journal、spool、锁文件仍为 `0600`，运行目录仍为 `0700`。
- 环境 token 覆盖不放宽含 token 声明文件的权限检查。
- 不支持的 Agent 平台保持现有明确失败行为；Windows 客户端继续使用现有平台实现。
- 文件替换、大小/时间变化、超限与非法语法检查保留；同一已打开句柄的重复身份比较可删除。

## 功能要求

- **FR-001**：所有本次涉及的只读私有材料消费者接受 `0400` 和 `0600`，继续验证现有文件所有者、类型及读取边界。
- **FR-002**：Agent 配置只解析秘密文件路径，实际读取/校验集中到任务和发布查询使用前；失败不执行外部动作。
- **FR-003**：构建与发布查询复用秘密选择规则；删除选择函数永远返回成功的错误通道与调用方死分支。
- **FR-004**：保留已知密钥的基础流式脱敏、现有鉴权、停止确认、文件锁及数据写入/恢复保护；不新增防护开关或依赖。
- **FR-005**：同步用户文档、验收与实施历史，说明配置加载不保证秘密文件可用；验收通过后一次本地提交。

## 关键对象

- 管理配置：已有客户端/Agent token 配置及发布诊断配置，不改变字段。
- 只读秘密材料：已有 env、SSH、通知、发布决定文件，不新增格式。
- 任务秘密集合：已有显式引用选出的业务秘密，不含控制凭据。

## 成功标准

- **SC-001**：各只读材料入口的 `0400`/`0600` 正例和公开权限/非法文件反例通过。
- **SC-002**：构建与发布查询的保留/排除规则一致，不存在永远成功却要求错误处理的选择步骤。
- **SC-003**：现有日志跨块、并发、取消与恢复回归通过；普通日志内容无丢失。
- **SC-004**：必要全量检查通过，代码没有新增依赖或防护框架，用户可从文档判断何时校验秘密。

## 假设

- 运行环境为可信仓库与专用构建账号，沿用当前部署边界。
- 用户未指定日志原样输出，默认保留简单的已知密钥替换；当前实现已是基础匹配，不为精简而替换有效算法。
- 本规范调整既有 006/007/012/014 凭据读取细节，其历史验收记录保持原样，当前行为以本规范为准。
