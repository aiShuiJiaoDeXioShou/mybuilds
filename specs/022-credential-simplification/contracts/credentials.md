# 凭据读取契约

| 入口 | 当前契约 | 失败位置 |
|---|---|---|
| 客户端/Agent token 配置、发布诊断 | 有 token 声明时自有普通文件，0400/0600 | 配置加载 |
| Agent secrets_file | 加载配置仅解析路径；使用时自有、单链接普通文件，0400/0600，最多 1MiB | 任务预检查/发布查询，外部动作前 |
| SCM 秘密/SSH 材料 | 自有单链接普通文件，0400/0600，现有大小与内容规则 | Git 命令前 |
| Webhook 秘密、发布决定 | 私有普通材料，0400/0600，保留原目录、单链接及内容校验 | 对应消费者读取 |
| 分发材料 | 沿用既有规则，0400 已支持 | 对应消费者读取 |
| Agent journal/spool/锁 | 0600；运行目录 0700 | 原写入/恢复边界 |

构建和发布查询复用同一显式秘密选择函数，控制凭据不进入业务秘密集合。HTTP 和退出码契约不变；Agent 配置成功不承诺 secrets_file 已部署。
