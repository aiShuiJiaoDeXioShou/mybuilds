# 功能规范：流水线初始化与安全预览

**Feature Branch**: `001-pipeline-preview`
**Created**: 2026-10-04
**Status**: 已实现，集成验证通过
**Input**: 用户授权完成 MVP；本功能交付初始化、严格配置校验、命名 build 选择及无副作用预览。

## User Scenarios & Testing

### User Story 1 - 初始化配置（Priority: P1）
开发者在空目录生成可预览的最小流水线，已有文件受到保护。
**Why this priority**: 为后续构建提供可编辑入口。
**Independent Test**: 空目录初始化后预览成功；重复初始化失败且原字节不变。
**Acceptance Scenarios**:
1. 空目录执行 init，生成一个名为 default、包含示例脚本步骤的配置。
2. 目标存在（包括符号链接）时拒绝覆盖；配置创建失败不遗留半写文件。
3. 指定有效本地模板时校验后生成配置，保留命名 build；无效模板不创建目标。
4. 尚未交付的平台模板选择明确报未支持，不生成冒充平台模板的配置。

### User Story 2 - 预览选定构建（Priority: P1）
开发者从单配置选择一个或多个命名 build，检查参数、条件和步骤。
**Why this priority**: 在实际执行前发现问题且不产生外部动作。
**Independent Test**: 双 build 配置分别按名称或全部预览，输出包含正确名称与参数结果。
**Acceptance Scenarios**:
1. 原根级配置表示 default；多 build 文件各 build 独立配置；混写拒绝。
2. 只有一个 build 可省略选择；多个必须指定名称或全部，未知/重复选择或两种选择同时使用报错。
3. 普通参数通过显式映射使用，触发覆盖优先于默认；未知、重复或约束不符的参数报错。
4. 已知参数条件给出满足/跳过及原因；缺少分支等事实显示待确定；手动预览不按路径筛选。
5. 包含脚本、上传、审批或报告的计划只展示，不执行、不联网、不读取密钥值。

### User Story 3 - 拒绝错误配置与保护敏感值（Priority: P2）
用户收到可定位且不泄露敏感值的错误，并发现非法或不完整配置。
**Why this priority**: 配置是后续宿主执行的输入边界。
**Independent Test**: 错误输入集均非零退出；脚本创建标记文件的配置预览后无文件，已设密钥不会出现在输出中。
**Acceptance Scenarios**:
1. 未知字段、重复字段、非法值类型、多文档、空文档、缺失必要字段或超限配置拒绝。
2. 只支持四种普通步骤，各种类的必填/专属字段检查，步骤名称唯一且安全；省略名称生成稳定名称。
3. 参数对象、条件、超时、收尾、报告以及通知均检查结构和引用；非法条件不当作跳过。
4. 未知模板变量报错；参数/环境字段可用模板，脚本文本保持原样；脚本、凭据与 Webhook 不回显。
5. 配置含上传时，普通构建/产物步骤必须在审批/上传段之前，不能在批准后替换产物；收尾只允许脚本/产物。

### Edge Cases
- 选择列表中空项、路径型 build 名称、全部与名称混用、空步骤列表、重复步骤名。
- 参数空值与 required/choices 的交互、默认值不在 choices 内、批量覆盖只在部分 build 声明。
- 条件字段间 AND、列表内 OR；参数条件失败且分支事实缺失时判跳过，只有未知条件才显示待确定。
- 路径绝对/向上越界、非法 glob、非法 duration、null 与别名/合并映射。
- 敏感标量出现在解析错误、步骤脚本、默认参数、通知地址及预览 JSON 中。

## Requirements

### Functional Requirements
- **FR-001**: 提供无参数初始化和本地模板初始化，拒绝覆盖任何已有目标，并使用排他创建保证竞态安全。
- **FR-002**: 支持版本 1；旧根级流水线规范化为 default，多 build 顶层只允许 version/builds/公共通知。
- **FR-003**: 严格检查结构、类型、未知/重复字段、必要值和唯一名称；拒绝空、多文档、别名/合并映射和超限输入。
- **FR-004**: 正确选择单/多 build，全部选择顺序稳定；不猜测名称，不隐式全部选择。
- **FR-005**: 参数为字符串简写或 default/description/required/choices 对象；声明名合法，默认值与最终值均满足约束。
- **FR-006**: 覆盖按第一个等号分割；拒绝重复、未知和批量未共同声明的参数；保留合法空值。
- **FR-007**: 校验 run/artifact/approval/upload 的专属字段、必要字段、shell、相对工作目录、路径模式与安全名称。
- **FR-008**: 校验正数执行 duration；post 只允许 success/failure/always 中的 run/artifact；报告只允许有效相对路径列表及 required。
- **FR-009**: when 只允许 branches/params/changes，字段 AND、列表 OR、参数 AND；拒绝空条件、未知参数和非法模式。
- **FR-010**: 预览确定参数条件；无分支事实显示 pending，changes 在手动预览忽略；保留判定原因及步骤位置。
- **FR-011**: 支持既定上下文与声明参数模板，仅对指定字段插值；run 正文不替换。未知模板变量拒绝。
- **FR-012**: 预览不会执行脚本、Git、网络、审批、上传或收尾，不解析秘密环境变量，不保存构建结果或伪造远端上下文。
- **FR-013**: 预览不回显 run/argv 正文、凭据、Webhook 或环境中的密钥引用值；解析错误只包含位置/字段/原因，不包含原输入标量。
- **FR-014**: 验证通知结构并脱敏，但不提前实现通知发送；仍可预览尚未实现的运行能力。
- **FR-015**: 含 upload 时 run/artifact 不得位于 approval/upload 发布段后；不含 upload 的普通审批不受此限制。
- **FR-016**: 非 dry-run 执行和未交付的平台模板明确报未支持，无隐式执行或降级行为。

### Key Entities
- 流水线文档：版本、命名构建集合、公共通知。
- 构建定义：执行需求、参数、环境映射、条件、预算、普通步骤、收尾、报告与通知。
- 预览：选定名称、参数约束结果、条件状态与原因、步骤清单、敏感信息隐藏标记。

## Success Criteria

### Measurable Outcomes
- **SC-001**: 全部初始化场景通过；已有目标在重复/并发初始化后原内容保持不变。
- **SC-002**: 单/多构建、参数覆盖与选择规则的正反行为均有可运行验证，批量选择不部分成功。
- **SC-003**: 全部结构/类型/约束/引用错误被拒绝，诊断可以定位相关字段或配置行。
- **SC-004**: 对包含副作用脚本与敏感值的配置，预览不产生标记文件、外部请求或敏感输出。
- **SC-005**: 条件满足、跳过、待确定三类均能展示；输出顺序可重复，现有帮助和版本行为保持可用。

## Assumptions
- 本功能不交付平台模板、实际脚本执行、数据库、Agent、发布或通知；对应功能稍后接入。
- 配置输入上限 1 MiB、嵌套上限 32、节点上限 10000；拒绝 YAML 别名/合并映射以避免隐式扩展与不透明继承。
- 当预览没有运行事实时使用 pending 占位，不调用 Git 或环境密钥解析；临时凭据只显示引用隐藏标记。
