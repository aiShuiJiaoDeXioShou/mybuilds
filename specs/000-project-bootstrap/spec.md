# Feature Specification: 项目初始化

**Feature Branch**: `000-project-bootstrap`

**Created**: 2026-10-04

**Status**: 已完成

**Input**: 采用确认的目录结构，初始化项目与 README，让 AI 入口指向 README 阅读项目概览。

## User Scenarios & Testing

### User Story 1 - 编译和运行双入口 (Priority: P1)

开发者能从同一份源码构建客户端和服务端，并查询各自帮助与共享版本信息。

**Why this priority**: 为后续功能提供可运行起点。

**Independent Test**: 分别构建两个程序，运行帮助与版本命令。

**Acceptance Scenarios**:

1. **Given** 已安装要求的开发工具，**When** 按项目说明构建，**Then** 生成两个独立程序。
2. **Given** 默认开发构建，**When** 任一程序查询版本，**Then** 显示版本、提交与构建时间的默认标识。
3. **Given** 任一程序，**When** 输入不存在的子命令或给版本命令传多余参数，**Then** 返回非零退出码与错误。
4. **Given** 任一程序，**When** 无参数运行或请求帮助，**Then** 显示可用命令并成功退出。

### User Story 2 - 阅读项目与继续开发 (Priority: P2)

开发者与 AI 从一个概览入口了解用途、当前能力、目录职责、构建方式和后续实施路线。

**Why this priority**: 防止把规划能力误当成当前已实现能力。

**Independent Test**: 检查 README 文档链接、复制运行其命令，并从 AGENTS 找到 README。

**Acceptance Scenarios**:

1. **Given** 新进入项目，**When** 阅读 README，**Then** 能区分当前初始化成果和规划功能，并找到产品计划与实施路线。
2. **Given** AI 需要了解整个项目，**When** 阅读 AGENTS，**Then** 被明确指引先看 README，并要求结构与入口变化时同步概览。
3. **Given** 本次功能验收通过，**When** 查看本地提交，**Then** 初始化实现及规范有一次功能提交，之前存在规划与工具基线。

### Edge Cases

- 未配置远端仓库：初始化及本地构建不依赖远端地址。
- 无版本注入：必须显示开发默认值；注入后两端必须显示指定值。
- 后续功能未实现：不得注册声称成功的空命令，也不得将规划中的命令作为当前操作示例。
- 当前功能不涉及构建执行、数据库、HTTP 服务或通知，运行帮助和版本不能创建构建工作区。

## Requirements

### Functional Requirements

- **FR-001**: 提供同一源码项目中的两个独立可构建入口，名称为 mybuilds 与 mybuilds-server。
- **FR-002**: 两端必须提供帮助与 version，版本结果含版本、提交和构建时间，支持构建时注入且有开发默认值。
- **FR-003**: 未知子命令和 version 多余参数必须返回非零退出码，不能静默成功。
- **FR-004**: README 必须用中文说明定位、当前状态、运行验证命令、已采用的目录职责与后续模块位置，并链接现存规划与规范。
- **FR-005**: AGENTS 必须引导阅读整个项目时先看 README，并要求相关变化同步 README，保留 Spec Kit 与每功能本地提交约定。
- **FR-006**: 规划与实施路线必须同步新目录；本次仅初始化必要文件，保留 001 及后续业务功能的编号和范围。
- **FR-007**: 必须建立 Git 基线，并在验收通过后将本功能的规范、代码、文档和验证记录一次本地提交，不自动推送。

### Key Entities

- **构建版本信息**：版本号、提交标识、构建时间；两端采用相同字段与默认值。

## Success Criteria

### Measurable Outcomes

- **SC-001**: README 中的双入口运行和构建命令全部成功，两端默认版本输出一致。
- **SC-002**: 两端帮助与无参数入口成功，未知命令及 version 多余参数失败，构建注入的版本字段与指定值相同。
- **SC-003**: README 中所有本地文档链接存在，AGENTS 明确引用 README，规划中不再出现旧入口和旧服务包路径。
- **SC-004**: 规范、计划与任务通过一致性分析，验收记录覆盖 FR-001 至 FR-007，本地提交后工作区干净。

## Assumptions

- 这是开发初始化，而非一次实现整套产品；001 流水线预览尚未开始。
- 暂无远端仓库，模块先使用本地名称 mybuilds。
- 目录按已确认结构随功能创建；不建立没有实现的业务包、示例或部署模板。
- 开发机为当前 macOS，客户端入口另外验证 Linux 和 Windows 可编译。
