# 多构建节点设计

本文件描述待实现的多 node 架构，是 [PLAN.md](PLAN.md) 的组成部分。
当前代码仅完成双 CLI 初始化，尚无控制端、Agent 或分布式执行能力。

## 拓扑与职责

```text
mybuilds 客户端 / Webhook
          │
          ▼
mybuilds-server 控制端（一个进程，Linux/macOS）
  ├─ 数据库：项目、构建号、节点、任务归属、审批、上传记录
  ├─ 调度：节点能力、项目允许节点、空闲容量、同项目同名 build 串行
  └─ 中央存储：脱敏日志、已完成上传的产物
          ▲ HTTPS：领取任务、心跳、事件与文件回传
          │ Agent 主动发起连接
          ├─ mybuilds-agent：macOS 节点 A（iOS / Android）
          ├─ mybuilds-agent：macOS 节点 B（iOS / Android）
          └─ mybuilds-agent：Linux 节点 C（Android）
```

客户端用于触发、查询和审批；控制端不运行用户的构建 shell。
Agent 在节点上检出指定 SHA，复用本地 run 的流水线引擎；本地只调试构建与产物，upload 统一由控制端持久化授权后在 Agent 执行。
同机部署也使用控制端与 Agent 两个进程；增加节点时沿用同一协议。
一期不引入消息队列、共享文件系统或 Kubernetes，不实现多控制端高可用。
这种控制端与执行节点分工参考 [Jenkins 节点模型](https://www.jenkins.io/doc/book/managing/nodes/)，
具体协议采用本项目的标准库 HTTPS 和数据库队列。

## 节点与任务分配

- 管理员创建节点并获取一次性显示的独立 token；控制端只保存摘要，支持撤销和更换。
  Agent 无用户/admin 权限，只能操作分配给自己的任务；节点端接口从 token 推导身份。
- 节点保存名称、OS/架构、工具能力、管理员标签、容量和最后心跳。
  自报工具检测结果用于诊断，不能自行取得受保护的发布标签或项目授权。
- 流水线 `runner` 声明 `platform: android|ios` 和 `labels` 字符串列表；管理员另设项目允许的节点集合。
  调度取平台、标签、项目授权与健康空闲节点的交集；无匹配节点时排队并显示原因，不退回任意节点。
  未声明 runner 时，仅在项目指定的默认节点上执行；项目也未指定时拒绝远程触发。
- 同项目同名 build 跨所有节点保持串行，不同 build 可并行；默认每节点容量为 1，全局上限默认 1，扩容时显式提高。
  节点有效容量取管理员设置上限和 Agent 本地 capacity 的较小值。
  iOS 须匹配 macOS、Xcode 与所需签名资源；Android 可匹配 Linux 或 macOS。
  Flutter 模板额外要求 Flutter 工具标签；商店发布要求锁定的 fastlane 工具与该应用的发布授权。
- 任务领取在数据库事务中校验并发、项目与 build 名称组合的互斥和状态，生成唯一 attempt、lease_id、递增 lease_epoch 和过期时间。
  首次排队任务才可选择任意合格节点；审批恢复排队固定原节点，再检查授权、工具、容量与封存证据，并允许该任务持有自己的 build 互斥。
  一旦开始，整条流水线固定该节点，不做逐步骤迁移。
- 一次多 build 触发固定一个 SHA，控制端先只读获取 YAML 并确定所选定义与快照，全部校验通过后事务创建独立任务。
  满足 build.when 的任务带 build_name 与批次关联，拥有独立项目构建号、节点、租约、工作区和结果；不满足的记录 skipped，不分配节点或构建号，失败不取消其他任务。
  多 build 允许 Android 在 Linux、iOS 在 macOS 分别执行，不等于一条流水线跨节点；项目允许节点和发布权限继续约束每个任务。

## 通信、租约与故障

- Agent 主动通过 HTTPS 领取任务与续租，无需开放入站端口；跨主机必须校验证书。
  建议心跳间隔 5s、租约 30s，均可配置；正式协议在 007 的 plan/contracts 中确定。
- 续租成功后 Agent 用本机单调计时估算保守执行期限；期限前未获得续租，停止接新步骤，
  TERM/KILL 本次构建进程组并清理签名资源。重连不能沿用过期执行权。
- 心跳、日志、步骤状态、文件上传、发布意图和最终结果均携带任务/attempt/租约标识。
  控制端条件更新拒绝过期租约、错误节点和重复终态；事件序号处理重发，不能仅凭 build_id 更新。
- 控制端重启后读取持久化租约并与节点核对，不能因为控制端重启就判所有构建中断。
  节点租约过期后任务标为 interrupted；停止证据不足时保存 stop_unconfirmed，保留同名 build 互斥、隔离原节点且禁止清理。
  原节点用独立身份确认进程回收，或管理员记录已停止的证据后才解除；过期租约不能提交执行结果，停止确认不解除应用上传 unknown。
- 已开始的任务失联不自动交给另一节点重跑。用户显式 retry 使用新构建号/attempt 和原 SHA、配置、参数；
  重试前须确认原进程停止，发布结果未知时还须单独确认。租约不能撤销已发往外部的请求，不能保证外部动作恰好一次。
- 运行中取消先持久化 cancel_requested，节点续租/轮询时取得意图并终止本次进程组。
  未领取的队列任务、已停在审批检查点的任务可由控制端事务取消；拒绝审批记 cancelled/approval_rejected，不启动用户 post。
  收到停止确认才展示已取消；节点失联时显示取消待确认，租约过期按中断处理，并保留外部副作用未知状态。
- 节点 drain 停止领取新任务，已有执行继续并保持续租；待审批任务恢复须等节点重新 enable。
  节点离线、禁用和删除的处理需测试。
  禁用先撤销执行授权并等待停止或过期；有活动或待审批构建的节点不得直接删除。

## 审批、日志、产物与密钥

- 到发布 approval 前，Agent 校验并封存产物、已配置报告与必要脱敏记录，完整回传控制端。
  确认步骤进程已退出、临时签名资源清理且检查点入库后，才释放租约、节点和全局容量。
  保留节点工作区、同项目同名 build 串行约束与节点归属；批准后在原节点以新租约恢复。
  节点离线则等待并提示，工作区缺失则失败；一期不把批准后的任务迁移到另一节点。
- 日志先脱敏再传输，按步骤/偏移去重；本地保留未确认的缓冲，控制端提供 SSE 与历史查询。
  限制缓冲与请求大小；不可无声丢弃日志，背压或缓冲耗尽时记录失败并停止任务。
- 产物用 HTTPS 回传控制端，临时文件写完后校验大小与 SHA-256 并原子发布；请求不能指定任意服务端路径。
  重发按产物标识幂等，节点失联时已确认产物仍可下载；待审批与未知上传结果的产物受 retention 保护。
- 构建 SHA 在控制端确定，按项目 auto/repo/profile 策略选择仓库配置或绑定方案；
  最终展开的流水线和参数在首次执行前落库并校验绑定该 SHA，记录来源及摘要，重试从快照恢复，不重新读取已变化的方案。
  控制端持有解析 SHA/轮询所需 Git 只读凭据，节点另有本地检出凭据与签名资源；执行/上传密钥按引用从该节点的受限 secrets 文件解析。
  通知目的地由项目直接配置或继承全局默认，敏感值由控制端受限保存并发送，不注入构建进程；
  租约响应不下发管理员 token 或完整控制端环境。
- 上传前由控制端持久化意图并授权当前租约执行；通知由控制端根据已持久化事件发送。
  授权后无可信终态回执即记 unknown，不依赖控制端猜测节点是否已发送；保持应用锁，不自动重发。通知失败不覆盖构建结果。
- MVP 保存 when 的条件输入与判定原因、累计剩余执行预算、收尾进度；节点按快照执行，审批不计执行时间，重启不刷新预算。
  post 仅在仍有执行权的原节点运行，失联不迁移用户脚本；系统进程/keychain 清理独立执行，已开始未知收尾不自动重跑。
- 日志含 UTC 时间戳、build/步骤/流与事件序号；JUnit 报告复用受限产物上传，失败用例在后续发布前阻止执行。
  项目 retention 控制中央产物、报告和节点工作区清理，执行前复核活动/审批/停止未确认/unknown 保护与下载占用。
  节点清理走独立管理指令而非终态任务租约：领取删除 ID/工作区 ID、确认无进程与路径边界、删除并幂等确认；离线时保持待清理。

## 存储与实施

控制端独占 SQLite 或 PostgreSQL；多个 Agent 通过 API 访问，不共享 SQLite 文件，也不直接访问数据库。
控制端 `~/.mybuilds` 保存数据库、日志与中央产物；节点独立 data_dir 保存工作区、日志缓冲和临时资源。
增加 PostgreSQL 不等于多控制端高可用；启动须取得 SQLite 进程文件锁或 PostgreSQL 专用连接 advisory lock，拒绝第二调度进程。
完整状态、请求幂等和文件入库规则统一见 [架构与状态](ARCHITECTURE.md#架构)，不在 Agent 另建状态定义。
